Limpar Cache do Navegador

🖥️ Windows / Linux

Pressione:

Ctrl + Shift + R

ou

Ctrl + F5

🍎 Mac

Pressione:

Cmd + Shift + R

ou abra o DevTools e clique com botão direito no ícone de reload e selecione "Esvaziar cache e recarregar forçado"

🌐 Alternativa Universal

1. Abra uma janela anônima/privada

2. Digite na barra de endereço:

file:////quiz-web/index.html

ou arraste o arquivo index.html para a janela
